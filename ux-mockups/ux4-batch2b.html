Past timesheets

Open You can import past hours and timesheet status until the first timesheet is submitted in CadenzPoint. After that, contact support.

  • One page instead of two ("Data import" and "Timesheet history import" merge), with the order shown as a numbered list and a check mark with a count once each kind has data.
  • Charge codes and charge code access can be imported (new). Today bulk setup still ends in blank timesheets because these two have no import.
  • One pipeline for every kind: choose a file → the server checks every row (today only past timesheets get a real check) → import → done. Problems are in plain words next to the row, with "Download rows with problems" to fix them in the spreadsheet.
  • Optional columns are optional (today an empty Ceiling Rate or Description rejects the row), and bad values are refused with a reason instead of quietly changed (an unknown role no longer becomes "employee").
  • Says up front whether past timesheets can still be imported — today you find out when the upload is refused.
  • Generated passwords for imported people still appear once, as today, with Copy and Download.
